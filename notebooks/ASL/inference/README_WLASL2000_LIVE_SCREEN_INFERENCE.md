## What it does

This notebook captures a selected screen region and runs WLASL2000 inference on it.

Useful for:

- YouTube sign videos
- Zoom / Teams / Google Meet signer tiles
- browser videos
- screen-shared videos

## How to use

1. Open the video or meeting.
2. Run the notebook until monitor preview.
3. Adjust `SCREEN_REGION`.
4. Run the live screen inference cell.
5. Press Q to quit.
6. Press C to clear transcript.

## Privacy

Only use this on content where you have permission to process the visual stream.
